# Catrissia Par — Portfolio Website

A responsive single-page portfolio inspired by the supplied moodboard. The visual direction uses a soft blush-pink background, cream panels, muted sage accents, warm beige details, serif headings, script accents, and floral illustrations.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, typography, and responsive styling
- `script.js` — mobile navigation, project filters, reveal animations, and current year
- `assets/flower-spray.svg` — original decorative floral illustration

## Run locally
Open `index.html` in a browser. The Google Fonts links use an internet connection; system fallbacks are included.

## Personalize before publishing
1. Replace the sample project preview cards with Catrissia's actual project names, descriptions, and images.
2. Update `your-email@example.com` in the contact button with the correct email address.
3. Edit the About section and focus/style details to match Catrissia's preferred introduction.

This is a static website and does not require a backend.
